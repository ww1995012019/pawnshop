# 太空当铺设计 P0 实施对应表

依据[原设计文档](page://page_f44de03a1914819194a52f23e05cf877)登记当前 `orbital-p0-v3` 的源码与素材对应。原设计Page及原始设计稿保持原有目标；本表区分已接入代码、已通过规则检查和仍需画面/生产验收的内容，不把条目存在视为完整成品交付。

## 主循环与范围

当前实现围绕“柜台接待/取证/报价 → 入库/加工 → 陈列或订单履约 → 仓储来源安检 → 日结及升级”。模型使用12AP、1200Cr开局与21日框架，首三天教学分别着重交易、维修原物、安检及首次二选一升级。24货物/6工具/6材料/5主要角色/12订单均在新版数据中，不再用旧站台12件货物和七日票币规则代替。

## 仍需保留的设计与制作边界

- 当前源码覆盖三场景/八页面的主要P0流程，但素材规格、可操作内容和浏览器验收分别记账；不得笼统写成“原文档全部完成”。
- 24件货物共享按工具类型组织的交互，5维修配方共享部分开盖/换件/接线/校准模板。每件独有多层拆件和专属动画仍需美术与动作制作。
- 仓格拖放、碰撞与旋转已接入；自动整理预览及撤销尚未作为完整功能交付。材料以资源数量保存，未作为独立可占格堆叠物渲染。
- 三派系关系与关注度独立记录，当前事件集中在首三天来源核验，不代表18个事件、完整回访剧情与21天完整叙事已制作。
- P0固定升级已有工作灯/销售架二选一；P1 UI-012完整施工、黑市、拍卖、物流、生活舱与高级来源图鉴尚未交付。
- 4K分层场景源文件、完整角色/设备骨骼、独立物品拆件包、最终音乐拟音、完整手柄控制与全部目标字号比例的验收仍需后续制作/验证。
