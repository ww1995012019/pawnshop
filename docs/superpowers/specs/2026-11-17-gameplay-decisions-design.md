# 第一批玩法规则修正

用户已确认先修改检查报告建议的第一批：陈列架/挂牌收益、基于证据的估价、避免机械磨价。本次保留此前横屏与共用控件修改，不改委修报价、经营结局或小游戏。

- 陈列架的5%加成进入合法自有陈列货物的新出售报价，允许与独立精品展区加成组合；不作用于买入、受托、未核验、隔离或已承诺价格。挂牌价是对客要价：在顾客接受范围内按挂牌价成交，超过预算时顾客仍按自身判断还价，不能用极高挂牌抬升预算。相同来客/原物的起始挂牌快照固定，避免反复改牌或移除重加刷价；已确认交易保持原约定。上架不重写手动价签。
- 玩家估价只使用型号公开参考、已记录品相、标识、编号、质量和可见加工痕迹。不能使用隐藏 authentic/working/内部缺件或旧 appraisalValue 推导区间；物证相同则估价相同。不同工具提供不同观察，正常读数不证明原装或走时；区间允许不缩小，始终非精确值。旧快照可保留读数并免费复核，不自动升级成新信息。NPC的独立知识和玩家主动出示证据机制保留。
- 自由还价保留。没有新证据的有效回合至少消耗一点耐心，小额让价不能完全抵消。反让幅度取决于真实让步及新证据，无进展不自动每轮向底价移动；每个有效回合至多生成一次反报价，重复查看/重报不能刷出新价格。保留合理多轮讨论、极端报价警告、单件拒绝和整场离开的既有边界。
- 单件、多件、刷新存档和已锁定交易遵守相同规则。报价本身不花钱/AP，也不转移原物；只有确认交割才入账。
- 用真实 reducer 回归复现审查中的问题；验证价格不越预算、相同证据不泄密、重复输入不刷报价及已确认金额不变。

## 实施记录

本批三项规则已接入单件与批量交易，保留此前横屏及共用控件修正。

- 陈列架：合法自有陈列货物的新出售议价基准与顾客预算提高5%；保留手动价签和已确认金额。同一来客不会因反复改价、移除重加或刷新而重新获取加成。
- 估价：依据公开型号参考、记录品相和实际物证计算。正常读数仍保留真伪与走时的不确定性；异常读数及加工痕迹可能扩大区间。旧读数保留并可免费复核。
- 议价：没有新证据的有效回合至少消耗1点耐心。反报价受真实让步与新证据约束，重复报价、查看和刷新不会凭空生成新的让价。
- 兼容：旧版已确认批量交易保留原金额，原物状态改变仍会阻止交割；单件转批量保留原物报价及讨论记录；已观察标识不会因无关维修或编号加工重新遮蔽。

已完成验证：147/147组原生回归；打包7项、字体1项、加载布局4项；桌面与手机横屏完整鉴定、加工复核与刷新存档；实际首位顾客的检验及连续议价流程。本地预览已更新。

首位顾客实测：两次正常物证记录的估价均为18–71 Cr，首次消耗1 AP；连续出价20、22、24 Cr时，顾客反报价46、45、45 Cr，耐心6、5、4，现金未发生转移。
