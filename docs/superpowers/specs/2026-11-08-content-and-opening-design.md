# 道具、人物、事件与开场舱门

用户要求再加 20 件道具、丰富人物和事件，并把开始页面换成「第几天」过场的样式。保留已完成的 v14 手机横屏大按钮与现有 Cocos 引擎。

本轮采用沿用当前系统的内容扩充：36 → 56 类实际货物，新增 4 位独立立绘人物（共 9 位），21 个每日经营事件，每个提供明确的选择及收支 / AP / 材料 / 关系结果；开场页与换天动画共享舱门、警示边和日期铭牌。20 件货物采用独立正反面图集，各自有用途、型号故障、工具组合；其中 8 件增加专用维修配方，并追加 8 张分期开放的委托。

相比只补名单，此方案让新增内容能到货、鉴定和进入业务；相比重建经营系统，沿用 reducer、21 日经营、每日六客、租金、经济与原物归属约束。人物具有背景、采购条件和不同场景的对白，人物档案可在界面打开。

事件是可选择的每日额外业务，不自动扣款，也不阻塞原有接客 / 新手流程。一个营业日最多提交一个事件结果，结果保存，拒绝重复提交；钱、AP 或材料不足时不发生部分扣除。已有 schema 3 档案仍可读取，原 12 / 24 张订单记录升级到 32 张时不重置完成状态或原物 UID。已存在实物的属性不得重新随机。

开场显示当前存档的第 N 天，使用与换天过场一致的金属舱门和琥珀日期牌；保留继续、新开店、帮助、设置及覆盖存档确认。手机主要触控区域保留至少 108 设计像素（在已验证尺寸下 ≥44 CSS 像素），不添加新的界面框架。

验收：新增内容与实际素材一一对应，56 件货物在 21 日供应中可见，所有新增人物可来访，人物采购条件在报价和交割处均生效；事件原子提交、去重与旧档迁移；原模型、几何、交易、订单与手机触屏回归；浏览器截图确认开场和换天风格一致、新素材无空图或串格。
