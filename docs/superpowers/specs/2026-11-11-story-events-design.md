# Cross-day shop events
User approved the recommended first three events: lost-watch ownership claims, returning-customer warranty disputes, and old-goods auction nights, with previews, an ongoing list, refusal and cooldown. Existing Godot game and saves remain authoritative; this is an additive release, including deployment under the standing instruction.

Design choices: claims start from an explicitly entrusted found watch rather than confiscating the player's lawfully purchased stock. Two claimants supply saved public records, compared against the actual original's fresh inspection; uncertainty permits station handoff. Warranty cases require an actual prior paid service and return that exact customer original, preserving serial and parts. Refunds, free rework, negotiated paid work and refusal preserve ownership and separate direct cash movements. Auctions show a saved physical lot in advance, permit two paid inspection tools, a budget ceiling and saved rival/round decisions; deposits are refundable and accounted separately from the full purchase.

All event modules expose ensure/view/reduce/observe. Claims recur no more than once per12 days, auction once per12 days offset from claims; warranty requires real completed work, a two-day return delay and per-original dedupe. Opening/reloading a view never spends money/AP, allocates a live UID, rerolls contents, duplicates custody or settles an event. Old saves begin their schedule on install day. Accepted cases persist across days and the day21 continuation. No hidden authenticity is displayed. No auto popup; compact event book with upcoming/ongoing/archive filters inside ShopPlan; real inspection and repair navigate to the existing workspaces. Cancellation/expiry return entrusted originals safely; funds never go negative and warehouse capacity failures are atomic.
