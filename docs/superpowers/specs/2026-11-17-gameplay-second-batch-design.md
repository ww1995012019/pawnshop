# 第二批玩法优化

用户已授权修改第二批三项。保留横屏、控件和第一批报价/估价/议价规则；在现有 Godot 模型中增加真实取舍，减少重复操作，让结局反映实际成果。

## 委修报价

采用公开、确定的服务费与熟客信任取舍，沿用现有熟客系统，不引入随机拒单。预算内仍可批准，超预算仍拒绝。

- 友好价：报价不超过预算的75%（向下取整），完成交付增加2点信任。
- 标准价：不超过预算的90%（向下取整），完成交付增加1点信任；作为表单默认价。
- 高价：其余预算内报价，完成交付不增加信任。
- 以上为新规则委修的总信任收益，受现有−6至6上限约束。新规则委修的维修完成不另送信任；维修履历照常记录。只报价、维修后退回、逾期或取消均不赚取这项信任。
- 接单、检查、报价不收服务费；真实维修、封盖和交付要求不变。只在原物交付时收取约定金额、消耗现有1 AP并奖励信任，重复提交或刷新不得重复结算。
- 批准时冻结规则版本、档位和信任收益。旧版已批准/可交付合同（含逾期后仍在保管的已批准原物）沿用原金额及旧奖励逻辑；不重建原物或故障。
- 表单在报价前说明阈值与收益、当前信任及上限；条件只取公开预算，不依赖隐藏故障、真伪或成本。

## 分项复检

- 放大镜、紫外灯、电子秤分别保存并判断物证的新鲜度：仅比较对应公开型号/实际读数/可见加工痕迹，不包含隐藏真伪、走时、内部元数据或其他工具的读数。
- 标识重描只使放大镜记录待复检；编号覆印只影响紫外；配重或改变实际质量只影响电子秤。加工如确实改变多个可见项目，则相应项目一起待复检。
- 品相记录独立于物证。品相变化保留未受影响的物证计数；没有与当前公开品相匹配的记录时，估价回到宽区间，并提示任选一项免费复核品相。任一有效复核即可更新区间，无需重做全部工具。
- 保留旧读数，不自动制造新观察。第一批安全快照可按记录的对应物证判定；更早且缺少安全物证的快照保持待复检，免费更新。
- NPC只学习玩家明确出示的那项记录；私下复检不会自动更新NPC，也不允许同一物证重复补充耐心。
- 私有交易完整性签名保持原线格式，已确认交易与标识可见性兼容不变。

## 经营评价与结局

新增只读评价模块，依据保存的实际履历，统计完成维修原物数、已履约订单、维修交付、检查过的公开型号/稀有型号，以及现金、账本净现金流和风险。不同证据对同一UID只计一次；翻新单个步骤、仅接取或未完工不算完整维修。旧档记录不足时明确为留存记录下限，不编造历史。

型号成果只按检查时记录的公开型号或精确型号履历统计，不从后来更换的外壳推定已经检查新型号。缺少此项旧履历时保留原物与物证，并可任选一项免费复核登记当前型号。

- 风险达到60仍为“高风险转运站”。
- 完成维修至少3件原物，可形成“可信赖维修店”；已检查至少3种公开稀有/名贵型号，可形成“稀有收藏行”。
- 两者均达标时，数量较高者优先；平手以完成维修优先。阵营关系不代替实际成果。
- 两者均未达标时，使用“稳健旧货铺”，仍可继续经营。界面说明当前成果和达成条件，履约与净现金流单列展示，现金流不称为利润。
- 第21天结算保存一次评价快照，继续经营时保留该快照。旧存档已保存的结局不重写；已有历史评价不从未来经营数据倒推。
- 破产清算、费用、经济账本、订单原物及持续经营的日序规则保持不变。

## 取舍与验证

委修随机拒绝会增加重报套利与解释负担，采用现有信任收益更清楚；复检不再用整件指纹；结局采用公开数量门槛，避免隐藏加权分数。上述阈值是本次实施选择，用户可在试玩后调整。

以真实 reducer/观察链证明：报价收益与信任取舍、取消不刷奖励、旧合同不变、分项复检与免费品相刷新、同物证不泄密、维修/收藏实际改变结局、评价纯读取与存档/继续经营一致。最后运行原生回归、导出Web并验证桌面/手机关键流程。

## 实施记录

三项规则已接入现有游戏与界面。经营计划提供友好价、标准价、预算价快捷选择，默认标准价，提交前展示实际服务费与受上限约束的信任收益；手机入口为“事务 → 经营计划 → 委托”。

鉴定台分别显示各项记录是否待复检。品相变化只需任选一项复核，不额外消耗AP；紫外和称重仍按原规则计电费。旧档缺少型号履历时，可任选一项复核登记当前型号，不从新外壳补算过去的收藏成果。

第21天保存真实成果与收支快照，继续经营时保留。旧合同、旧结局及已确认交易不重写。另修复了手机提交报价时同步重绘移除当前触摸按钮的问题，新增真实触摸回归，验证一次点击只批准一次且不提前扣款。
