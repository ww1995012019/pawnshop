# 初始化加载层与手机交互动作修正

用户明确指出要修改的是浏览器初始化时的蓝色加载层，并反馈手机交互缺少动画。本次沿用已经指定的第 N 天金属闸门外观，修正对应页面与已有动作在手机布局上的连接，不另换游戏题材或经济系统。

加载 HTML 使用无外部素材依赖的灰黑闸门、警示边和琥珀日期牌；从存档读取有效日期，保留真实阶段文案、加载失败与重新打开。手机仪器弹层显示当前原物、正背面、读数与大按钮，操作当下播放局部镜头/UV/谱线/回路/天平/负载反馈。前三步维修、扫描与交割对齐真实实物和现金读数，接客递物和离场改用手机坐标。实物翻面、旋转和对白也有短反馈；动画不更改经济与原物归属。

采用复用现有原生 Cocos 动作与绘图的方法，避免额外渲染框架；HTML 只负责引擎启动前的加载层。保持 667×375 / 844×390 按键至少 44 CSS 像素，尊重减少动态、可中断并清理临时节点。

验收：先复现蓝色加载层、桌面递物坐标与手机工具无步骤动作，再用真实触摸验证阶段画面、费用不提前扣除、动画对齐与清理；原手机业务和规则回归；构建 v16 并发布用户此前指定的 GitHub Pages 地址。
