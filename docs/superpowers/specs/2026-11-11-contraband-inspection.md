# 警官赃物抽查调整

已确认口径：按关注度计算，关注度每1点对应0.03个百分点，即概率为关注度×0.03%。12点为0.36%，100点为3%。违禁品在本次需求中仅指赃物，普通仿品和来源待核物不属于这一范围。

沿用第3天起每天生成一次抽查结果的时机，在生成当日日程时按当时关注度记录概率与抽签结果；切页、整理、读档不重复抽签。既有存档已经排定或已经完成的抽查保留。

警官到场后等待玩家整理。界面提供“先整理物品”，可进入仓储将货物放入隔离箱；不会因打开仓储、移动货物或等待而自动开查。玩家点击“整理好了，开始检查”后，按确认时的实际库存检查。

检查只处理店铺自有、未被委托占用、位于非隔离区域的实际赃物。隔离箱中的物品完全跳过，不没收、不计罚款、不因箱内案件记录另行追罚。仅来源待核、普通仿品和已卖出的历史案件记录不作为本次现场发现。

发现一件或多件赃物，没收本次现场查到的全部赃物，本次应罚总额固定30 Cr；未发现则不罚款。重复提交检查不重复没收或罚款。取消旧的按货物价值比例处罚和本次查货的协警免罚；不额外扣站务关系或增加关注。现金不足时沿用现有非负余额规则，回执分别显示应罚30与实际缴纳额，不新增隐性债务。

没收后的实际原物从库存移出并在案件记录中标明警方接收，不能因为旧的原主追回逻辑重新出现在隔离箱或库存。抽查结果随存档保存，桌面与手机显示相同准备和确认流程。
