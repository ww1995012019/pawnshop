# Counter quick list

The user requests a PC right-hand item list when a normal customer arrives,
with actions directly on each original. They selected: choose several items,
then settle the whole batch for **1 AP**. Current comic art and physical table
remain. Also remove the transparent gap below the visitor's hands.

The panel lists all visitor originals and shop originals currently presented,
with thumbnail, name, quote, evidence/status, select/unselect, inspection and
negotiation. More actions retain pawn, reporting and other existing guarded
verbs. Table focus and list focus stay linked. Only overflow scrolls. A fixed
summary/checkout row shows selected count and actual net cash; orders, people
and send-off remain reachable. Ordinary customers use the new list; special
visitors, idle and own-original previews retain their working views.

Use existing CounterDialogue and TradeSession confirmation/checkout rules.
Selection changes no money/AP. Checkout uses current trade ID, session version,
batch ID, original UID/fingerprint and existing eligibility/source-risk guards.
Stale controls must not act on another visitor, quote or original. Inspection
returns to the same list. No automatic checkout or per-item AP charge.

Approach: replace the large ordinary-trade detail panel with the native list,
and open compact per-item negotiation/details on demand. This meets direct
list operation without squeezing every editor into every row. The portrait
fix trims transparent atlas padding and aligns the painted base to the counter;
original artwork is retained.
