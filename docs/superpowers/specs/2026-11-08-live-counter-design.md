# 可操作柜台、三件道具与铺满视口

用户已接受先把一个柜台和三件道具做精的方案，并进一步指出两侧黑边、展示物不能直接操作、场景像贴图。本次目标为可完整操作的原生 Cocos 样例，继续保留现有经营内容与已授权 GitHub Pages 网址。

采用分层 2D 实物：循环水芯的壳体/上盖/滤芯，离子保温杯的杯身/杯盖/加热底座/旋钮，光合灯的底座和三片独立灯叶。三件均使用统一磨损合金、暖铜与玻璃材质的新素材，组件独立移动、旋转并有阴影/灯光。它们出现在柜台的实物陈列位，可直接拿取/拖到工作垫、操作部件、放回或到鉴定台；鉴定台继续显示同一件的部件状态。实体动作能解锁本件观察记录，记录明确调用原 CHECK，首次鉴定 AP 与原物 UID 不变。展示不自动挂牌出售、复制库存或改变归属。

全屏采用填满画布的自适应视口与背景，保留交互控件完整可见；另提供浏览器全屏按钮，失败时给出可理解的提示。宽屏、手机横屏与竖握旋转都需要检查，避免以裁掉 HUD 的方式消除黑边。普通业务页面、存档 schema 3、现有原物/费用约束和减少动态设置保留。

本轮范围是一个柜台与三件代表道具，其他型号继续使用已有表现。部件装配的检视姿态在本次游戏会话中保留；不引入脱离现有交易的免费材料或自动维修。拿放取消、窗口失焦和页面离开都要结束拖动，已成交/隔离/他单原物不能从展示柜重复拿取。

验收：1920×910、1920×1080、2560×1080、667×375、844×390 画布铺满且控件不裁；陈列物取用、取消/放回与重复拿取不会复制或扣费；三件有至少两帧不同的独立部件位置和状态反馈；观察记录只扣正常首次 AP；同一 UID 从陈列到检视保持一致；完整规则及手机业务回归；实际画面/连续操作记录并发布。
