# 横屏手机操作优化

用户确认横屏，保留现有工作台画面与原生 Cocos 渲染。手机尺寸下原有按钮仅高 17–27 CSS 像素，本轮以常用触控目标至少 44 CSS 像素为验收目标（667×375 及更大横屏尺寸）。

采用手机专用布局；桌面与平板保留现有布局。继续使用原 reducer、存档 schema、经济与归属规则。只扩大字体无法解决按钮尺寸和同时展示过多信息的问题；整页缩放则会裁掉操作，因此不采用这两种方式。

- 手机顶栏精简为经营读数和大尺寸帮助/菜单入口，六项底栏使用 110 高的实体按键。
- 柜台保留顾客与实物，交易终端放大；议价编辑与证据选择有大尺寸控件。
- 鉴定保留实物观察，六个工具与旋转、翻面、缩放、归位按钮扩大。仪器操作提供逐步点按面板，完成条件、消耗与复测规则保持一致。
- 仓储、维修、订单以大卡片点选实物，分离详情和操作。使用同一模型校验，交付必须预览并明确确认；仓位可在大格子面板点选。
- 设置、日结和确认弹窗使用可读文字、大尺寸返回/确认键。安全边距、竖握旋转及窗口变化纳入浏览器检查。

原画、剧情和游戏内容不在本轮重做范围。辅助点按替代小尺寸拖动，不自动取得证据或改变判定。

验收：自动化真实触屏输入检查主要页面、接客—鉴定—议价—交割、仓储动作、订单及取消确认；667×375、844×390、竖握旋转、桌面和大字偏好；运行原有测试、类型检查与正式网页构建。实体 iOS/Android 的系统全屏行为仍需实机核验。
