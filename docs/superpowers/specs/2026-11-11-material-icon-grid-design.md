# 商人材料图标网格

用户已确认深绿、铜色的小图标横排方案，并要求开始修改。

- 目标：材料以等宽图标卡片排列；卡片显示名称、商人库存和持有量。选中后在下方统一选择数量、购买或出售。
- 全部保留：当前源码共有 13 种材料，不只截图中的九种。宽屏最多五列，窄屏减少列数；选中项使用铜色强调。
- 沿用 Godot 原有 UI 皮肤与 BUY_MATERIAL / SELL_MATERIAL 规则。交易后保留选择、数量和键盘焦点，刷新现金、库存、总价和禁用状态。
- 材料耗尽、现金不足、持有不足时禁用对应按钮；数量范围为 1–99，与现有交易规则一致。批量交易继续由原有 reducer 校验。
- 方案：采用图标网格加共用交易区，减少重复按钮；保留逐行买卖会延续原先冗长问题；纯图标方案不易辨认，因此保留名称。
- 范围：随行货与旧表回收行为不变。此分支只做本地修改和验证，不发布。

实现决定：新增独立 MerchantMaterials 控件，用单个透明像素图集提供材料图标；由柜台现有刷新流程承接交易。
