# Game feel implementation plan

**Goal:** Make the existing browser game feel tactile and responsive through object contact, customer reactions, playable instrument feedback and a compact game HUD.

**Design basis:** Current v9 screenshots and the user's feedback that the animation is weak and the presentation does not feel like a game. Keep the existing old-port industrial art, Cocos Creator 3.8.8, six actual instrument procedures and reducer semantics. This is a direct implementation pass, not another design-option approval loop.

- [x] Motion: remove stretched glove/sleeve handoffs; slide a rigid item onto the actual counter with a contact shadow, braking and settling. Arrival plus delivery at most 1.22s. Pass the actual current item center to deal to eliminate the trade-page 40px jump.
- [x] Customer: add brief agree/counter/refuse reactions using current mood atlases and restrained body motion. Dialogue reveals progressively without locking input and can be revealed immediately.
- [x] Inspection: immediate local evidence contact, pick-up/drop feedback and real cable endpoints while retaining the unchanged logical pose and hit geometry.
- [x] Repair: actual object contact shadow, stage-specific cover/insert/circuit feedback, no duplicate generic welding effects or repeated completion panels. Preparation never commits materials or AP.
- [x] HUD: compact instrument plates and AP segments; six physical toolbelt icons with clear labels; button visual surfaces depress 2px while hit rectangles stay fixed.
- [x] Scheduling/audio: small local effects do not lock the entire game. Large handoffs/transactions retain skip and one-time commit protection. Use existing drop/open/check/reject sounds at matching actions and preserve saved sound preference.
- [x] Verify: model/type/build checks; sequential native-pointer browser QA, state invariants, cancellation/reduced motion, actual intermediate animation frames and video; visually inspect screenshots at desktop and smaller viewport.
- [x] Release the verified artifact through the same private Site, retain audience, source provenance and a short actual gameplay recording.
