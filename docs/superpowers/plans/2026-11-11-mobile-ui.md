# Mobile UI Implementation Plan

**Goal:** Make phone buttons, dialogs and management lists readable and operable in both orientations while preserving the shop's visual style.

**Architecture:** Share phone metrics in UIKit; constrain dialog geometry to the viewport. Use compact summaries with expandable details for orders, responsive warehouse details and an accounts-first ledger. Keep reducers and game rules unchanged.

**Tech Stack:** Godot 4.6.3, GDScript, Python/Playwright.

**Spec:** User-approved proposal in this conversation (2026-11-11).

## Constraints
- Retain desktop presentation and existing business rules.
- Phone content must fit horizontally, long content scrolls vertically.
- Keep close controls visible; preserve focus restoration and input blocking.
- Avoid shrinking text to obtain additional rows.
