# 最后一轮收尾验收

范围：只复验现有两批规则和原手机界面要求，修复实际复现的问题，不新增玩法。

验收路径：

1. 当前版本的桌面按钮边界、关闭、下拉列表与工作区返回；手机横屏及竖屏旋转布局。
2. 从新游戏进入首位顾客，检查、选购、实际交割、送客、日结与次日营业，保存当前截图与状态证据。
3. 正常初始现金/AP/材料下的确定经营路径；报价、维修、租金及重复动作；不凭直觉调数值。
4. 旧版已批准合同、原物UID、鉴定记录、21天成绩及继续经营的真实派发/JSON读档兼容。

已复现修复：

- 工作灯说明与实际AP规则不符：当前规则对每件原物首次记录免AP，旧文案写“每天第一次”；鉴定台又始终写首次1AP。统一说明，并按灯具是否安装显示当前费用，不改AP或经济规则。
- 默认共享浏览器缺少WebGL2时，加载页明确返回功能缺失，却仍让玩家“检查网络”。兼容错误改为更新浏览器/检查图形功能的指引，按钮为重新检测；真正网络错误保持重试。先复现再加入缺失WebGL2/网络错误区分回归。
