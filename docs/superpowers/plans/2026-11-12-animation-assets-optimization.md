# 动画与素材优化实施计划

**Goal:** 保留完整动画与交互，减少纹理像素、重复分配和无效计算。
**Spec:** docs/verification/2026-11-12-animation-assets-optimization.md
**Architecture:** 沿用 Godot 图集与现有世界坐标，图集使用逻辑像素，合成贴图使用统一单元转换；可复用资源缓存，动画状态继续实时推进。
**Tech Stack:** Godot 4.6.3、Python Pillow、JavaScript。

## 约束

保留所有工序、光学观察、标识遮挡、存档和输入判定。未取得 GPU 数据的画质降级不实施。当前云端 work 分支原地执行，避免转移未提交的检查文档。

## 实施与验证

- [x] 图集减半，单元裁切统一换算；像素往返测试与实物、鉴定、加工回归。
- [x] 工作台 StyleBox 复用；保持现有绘制顺序与动作状态机。
- [x] 普通预览停止无效时钟更新，实物外观按状态引用和修订同步；珍稀动画持续运行。
- [x] 划痕按镜片覆盖计算；不改变接缝与已发现物证。
- [x] 复用人物网格，保持实例材质独立；未复现的 Tween 冲突暂不更改动作时序。
- [x] 实际打包与全套原生回归，记录结果与仍需真机验证的项目。

## 性能取舍

高分辨率画稿有损压缩、选中光晕减少采样、子视口降分辨率属于需图形对比的建议，本轮保留原画质。背景只在明确保持世界坐标时缩小，不暂停仍可见场景。

## 实施记录

共享平面法线使用单个1×1 ImageTexture；合成纹理缓存最多64项，淘汰只释放缓存引用，仍在展示的纹理由节点持有。原有法线源文件保留用于素材回归。

独立审查发现并修复：原图与烘焙变体切换的缩放、UV 中心重复缩放、状态牌背景裁切。均加入资源回归测试。

取舍：保留原有绘制层次、人物动作时序、子视口质量和49次采样光晕；静态分层、UI事件化和高分辨率画稿压缩需要额外图形性能对比后独立实施。此前代码检查的流水、业务存档与网页事件包装器问题不混入本次素材改动。

验证完成：npm test退出0，原生83/83；浏览器桌面／触屏三工具与加工流程通过，最终构建桌面复跑通过。资源占用退出告警仍有出现。
