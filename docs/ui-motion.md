# 轨道旧货局原生 UI 与动画

当前表现层按空间站方案的 UI-001..008 与 SCN-001..003 组织，版本为 `orbital-p0-v3`。冷青用于设备和取证，锈橙用于报价和经营确认，暗紫用于来源、特殊货物与派系信息；文本保持高清中文，场景、人物和可操作货物共同承担信息。本文描述已接入代码的范围，完整三天浏览器110项检查已通过；26项收尾回归与5项最终校验也已通过，见 [验证记录](validation.md)。

## 页面与空间

`CreatorMain` 继承 `OrbitalMain`。`OrbitalUI` 使用真实 Cocos `Node/Sprite/Label/Graphics/Button/EditBox`，`OrbitalPanels` 处理维修、仓储、订单与日结。底部固定六项导航：柜台、鉴定、维修、仓储、订单、日结；议价由柜台进入，设置由顶部进入。业务页面保持顶栏与导航，确认性操作才弹出短对话窗。

| 页面 | 核心可见内容 |
| --- | --- |
| UI-001 营业主柜台 | 空间站店面、来客、柜台实物；日期/AP/现金/租金；订单和三派系/关注度信息 |
| UI-002 实物鉴定 | 左六工具架，中间可拖动/旋转/缩放的正背面货物，右侧证据与估值；下方当前工具操作 |
| UI-003 维修拆解 | 库存选择、开盖实物、备件槽、连接/校准/复测、材料和最后提交；不可逆拆解单独确认 |
| UI-004 仓储安检 | 10×6占格仓库、销售架、扫描区、来源/封存、隔离与抵押保管柜 |
| UI-005 议价成交 | 证据卡、报价调整/输入、报价与原物、现金支出预览及抵押合同 |
| UI-006 订单委托 | 12张订单、开放日/期限、归属与交付条件、拖入原物的交付区域 |
| UI-007 日结租金 | 现金流图、费用与流水、下一日安排、第3日日结的工作灯/货架二选一升级 |
| UI-008 暂停设置 | 声音、减少动态、放大文字、档案导出、重新开始 |

三个场景视图在同一原生 Creator 启动场景内切换：柜台与议价使用 `orbital-counter`，鉴定与维修使用 `orbital-workbench`，仓储与安检使用 `orbital-warehouse`。这并非已制作8个P1场景。

## 实物、人物与动效

`OrbitalMotion` 是独立表现层，提供开启舱门、顾客进出、呼吸待机、手持递物、钱币票据、扫描/显纹/谱线/探针/称量/脉冲、维修/组装、印章、升级与日切效果。浮尘与状态灯作为低干扰环境动态。当前五位角色使用常态、专注、疑问、满意、拒绝、疲惫六组姿态/表情图集；来访、取证、还价、接受、送客及第3日疲惫等阶段切换可见反应，并配合位移、呼吸摆动、透明度和四姿势手部。它们不是 Spine 骨骼、完整口型或逐帧行走成品。

货物使用独立正面与背面图集；`F` 切换视图，`R` 旋转，滚轮/按钮缩放。故障裂纹、开盖结构与维修补片还结合程序绘制。维修操作包含拆盖、拖件入槽、接线或标靶/配重校准及确认复测；提供辅助装入/接线入口，操作不依赖极短倒计时。组装需要两件真实主料放入槽位并完成端子连接，模型确认后主料才消耗。

交割与订单先保存资金、AP、原物归属和事务ID，再播放视觉结果。快进只结束表现，不重放账务。减少动态省略大位移和装饰运动，保留最终状态与必要文字/轮廓反馈。面板启动以稳定命中区域和透明度反馈为主，避免控件在操作时持续偏移；实际目标和相机坐标由原生 UI 命中检测处理。
