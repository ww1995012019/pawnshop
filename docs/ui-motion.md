# 原生 Cocos UI 与动画说明

本轮界面标识为 `creator-web-v2`，基准分辨率为1600×900，使用SHOW_ALL适配横屏浏览器。核心浏览器检查已37/37通过，完成22次真实鼠标动作；日切与跳过的精选复核通过，最终构建另通过25/25精选检查，袖口遮挡已移除，柜台物品同步恢复。具体结果统一写入 [验证记录](validation.md)。

## 场景与界面素材

界面由真实Cocos `Node`、`Sprite`、`Label`、`Graphics`、`Button`与透明度/变换组件组合。网页负责画布和加载，游戏内界面在Cocos场景中运行。

| 素材 | 本轮用途 |
| --- | --- |
| `shop` | 店铺背景，承载门口、柜台与货架空间 |
| `characters` | 六位顾客的立绘、来访名牌与交易对象 |
| `items` | 十二件旧物，用于柜台、鉴定台、库存、陈列与递放 |
| `hands` | 左手张开、左手握持、右手张开、右手握持四种独立手势 |
| `frame-actions`、`frame-dialogue` | 木质操作按钮、窗口标题与柜台对话框 |
| `notice-board`、`receipt-paper` | 今日告示、交易单、现金/日数卡、标签与成交票据 |
| `cabinet` | 库存与陈列格的实物木柜边框 |
| `ui-icons` | 状态栏与柜台对话功能图标 |

`folio`、`manual-book`、`commission` 素材仍随工程保留，本轮尚未接入界面；图鉴、账本与鉴定信息使用纸张和原生排版。

图片原件保存在 `assets/resources/art/`，原生资源导入元数据随工程保留。按钮须覆盖悬停、按压、选中、禁用和键盘焦点；纸张与边框作为界面材质使用，文字仍由可读取的Label呈现。窗口须保持标题、返回/关闭与主要操作可见，图文不能相互遮挡。

## 动画与交互触发

`GameUI.ts`负责界面节点与局部反馈，`MotionDirector.ts`负责表现时序，`CreatorMain.ts`把经营动作接到表现层。下表说明功能与目标；其中扫描、热点、电流、波形、编号、结果印章，以及交割/上架的可见中间帧已完成本轮核心实测，日切和跳过另完成精选复核。

| 时机 | 表现与验收目标 |
| --- | --- |
| 启动进店 | 带横向板条的开店卷帘向上揭幕，店名淡出，场景露出后可接待 |
| 店内待机 | 顾客轻微呼吸摆动，灯光缓变，浮尘在照明区域漂移 |
| 接待顾客 | 立绘走入柜台区域，有步伐摆动与淡入，结束后稳定停在交易位置 |
| 递物与取物 | 伸手、握持、搬运、释放、收手分段；四手势按方向与阶段切换，使用图集自带袖口，旧物沿弧线移动并带接触阴影；原生Mask限制手层范围，避免遮住底部操作 |
| 痕迹检查 | 扫描带与放大镜掠过物品，实际点击痕迹后记录证据 |
| 编号对照 | 扫描线与编号条随进度变化，结果对应玩家选择的编号 |
| 功能鉴定 | 采样柱、触点连接线、电流光点与负载波形呈现测试过程；波形状态对应物品功能 |
| 鉴定/议价结果 | 印章缩放落下并淡出，文案区分已记录、已核验和议价达成 |
| 收购/出售交割 | 钱币往柜台或钱包方向移动，金额反馈、票据滑入与递物同时配合；经济结果以模型提交的一次交易为准 |
| 陈列上架 | 旧物递放至指定陈列格，结束后的真实货架与所选格位一致 |
| 送客/交易结束 | 顾客走离柜台并淡出，不留下重叠立绘 |
| 打烊/次日 | 遮罩淡入淡出，显示打烊或新一天标题；已验证打烊可返回营业，确认结算时报告页存在活动遮罩，随后进入第2天并释放操作锁定 |
| 通用操作 | 按钮按压回弹，提示与窗口保持层级清楚，动态不吞掉后续输入 |

## 时序与边界

动画只负责表现，不在完成回调中额外变动现金、库存或鉴定费用。交易去重、日切和存档以经营模型为准。本轮已经验证双击交割只入账一次，刷新后金额、物品UID与格位一致，交割中途刷新不重复台账；后续精选复核确认打烊、报告与次日衔接。

播放期间提供操作锁定与跳过入口。精选复核已确认Space跳过入场不重放交易并释放操作锁定，Esc跳过送客保持一次拒绝。启用“减少动态”时应立即结束或省略过渡，保留最终状态和正常操作；本轮已测得立即生效且连续两帧动态位置变化为0。刷新后的设置与游戏存档需一致。关闭窗口、重置游戏或切换页面后，不得残留手部、票据、遮罩、连线或永久锁定。

当前角色动作由整体立绘的位移、轻微摆动和透明度实现；手部使用左右张开/握持四种姿势的手套图集，袖口收尾目标是仅保留素材自带部分。完整角色逐帧行走、口型、骨骼表情、物品独立正反面/拆件与更多工作场景需要继续补素材，尚不计入本轮范围。

## 验证范围

官方3.8.8源码引擎的浏览器构建已经运行，支持真实Sprite、Label和Graphics。本轮类型检查、127项模型检查与网页构建再次通过，核心浏览器检查及日切/跳过精选复核无控制台、页面或资源错误；最终构建另完成25项精选检查；袖管遮挡已移除，柜台物品改为同步恢复。此环境没有Creator编辑器，因此Dashboard导入、资源重导入和正式编辑器构建仍未本机验证。
