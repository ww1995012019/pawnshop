# 轨道旧货局原生 UI 与动画

当前表现层按空间站方案的 UI-001..008 与 SCN-001..003 组织，版本为 `orbital-p0-v6`。视觉方向为“旧港仪器店”：烟熏玻璃、磨损合金、橡胶托槽与暖白丝印共同构成操作界面，琥珀标出主动作，青色集中用于读数、扫描和当前工具。本文记录当前设计与已接入素材；本版本的实际画面和交互验收结果见 [验证记录](validation.md)，旧版通过数不替代本轮结果。

## 页面与空间

`CreatorMain` 继承 `OrbitalMain`。`OrbitalUI` 使用真实 Cocos `Node/Sprite/Label/Graphics/Button/EditBox/Mask`，`OrbitalPanels` 处理维修、仓储、订单与日结。底部六项导航嵌入台沿控制导轨：柜台、鉴定、维修、仓储、订单、日结；议价由柜台进入，设置由顶部进入。经营读数与导航位于独立的顶底界面层，页面内容、实物和常规特效各用自己的区域，不随物体拖动或旋转。

柜台的层级依次为舱内背景、半身顾客、原画前景台沿、台面实物与手部、局部终端和字幕。人物按自然比例呈现，并由遮罩与原绘台沿建立遮挡关系；两侧终端只承载当前任务和交易信息。鉴定中央不再另铺大块蓝色面板，工作垫直接承载可拖动实物；工具插槽、证据读数与台沿小控件保留操作空间。

大读数、正文、仪器标签和辅助说明分级排版。界面材质集中在主操作、工具托座与导轨；次要按钮减少纹理和亮边，避免每个矩形都争夺焦点。普通标题和正文采用暖白，报价确认使用琥珀，测量与选中状态使用克制的青色。

## 鉴定台的姿态与边界

鉴定物体以中心为旋转轴；工作垫范围为画布上的 `(244,216,992,366)`，四周保留 8px 内边距，并由 `Mask` 裁切。`InspectionGeometry` 根据旋转、比例和镜面后的四角包围盒限制位置；每次拖动、滚轮缩放、按钮缩放、方向键移动及旋转都先应用约束。当前图集单格为正方形，`contain` 在 524×404 的绘制区域中得到 404×404 的可见 Sprite，因此约束采用中心两侧各 202px 的实际图像包围盒，不把透明横向留白计入宽度。

归位比例为 80%，中心为 `(740,399)`。缩放输入范围为 45%–135%，最终比例还要适应当前角度的工作垫容量：0°/90° 上限约为 86.6%，45° 上限约为 61.3%。界面直接显示实际百分比，到达当前容量时标出“显示上限”并禁用继续放大。任意角度放不下时先缩至可容纳比例，再约束中心；几何层允许适配比例低于传入的最小缩放值，并处理非有限输入。独立回归以四角变换检查旋转、镜面、缩放与极端拖动，运行命令为 `npm run test:inspection-geometry`。

姿态按当前选件隔离：切换另一件货物或点击归位，会回到中心、80%、0°和正面；同一件货物切换工具、翻面或重绘时沿用当前位姿。拖向工具架时，工具选择根据指针释放位置判断，物体仍受工作垫约束。阴影根据变换后的包围盒更新位置和宽度，拖动时收窄并变淡；疑点、编号、谱线标记和探针接点使用物体局部坐标，随货物平移、旋转和缩放。

## 通知、弹窗与成交状态

普通通知放在顶栏下方的 28px 单槽信息条中，后来的消息替换前一条，短暂显示后淡出。弹窗打开时清除并隐藏背景通知；弹窗关闭后重新开放通知槽，不堆叠旧消息。弹窗遮罩阻止背景指针输入，键盘焦点也限定在当前弹窗：`Tab` 遍历弹窗按钮，确认键只执行弹窗内焦点项，`Esc` 关闭弹窗；物体旋转、翻面和背景页面快捷键在此期间不触发。文本输入框保持自身输入优先。

交易接受报价后进入锁价状态，报价区域只读；鉴定、还价、拒绝和抵押等交易选择从当前终端移除，右侧仅保留“确认钱货交割”主动作。现金、AP与原物归属在执行交割时结算，接受报价本身不充当交割。成交后的回执和金额反馈位于业务区域，顶部余额显示已提交的状态。

## 字体与行对齐

单行标签采用字号行高；多行说明显式设置换行与段落行距。混合字号的金额、单位和状态通过`baselineLabel`共用字母基线，按锁定3.8.8 Web文本布局计算；不使用空格拼接数值列。原生EditBox会在绑定Label时改写垂直对齐，初始化完成后恢复CENTER。按钮保持固定命中几何，标签居中；大字模式沿用同一行基线与列宽。

## 实物、人物与动效

`OrbitalMotion` 是独立表现层，提供开启舱门、顾客进出、呼吸待机、手持递物、钱币票据、扫描/显纹/谱线/探针/称量/脉冲、维修/组装、印章、升级与日切效果。开场舱门使用临时全屏层；常规特效局限于业务区，鉴定效果进一步裁到工作垫与当前物体范围，印章、升级和日切使用紧凑提示。环境动态只在柜台和议价保留少量暗浮尘与顾客轻微呼吸；仪器和管理页面不铺常驻漂浮装饰。离开页面、快进和销毁时清理旧动画及节点。

当前五位角色使用常态、专注、疑问、满意、拒绝、疲惫六组姿态/表情图集；来访、取证、还价、接受、送客及第3日疲惫等阶段切换可见反应，并配合位移、呼吸摆动、透明度和四姿势手部。进出均沿用台后半身比例和遮挡。手递物体沿短弧线移动，手部接触点跟随货物，阴影跟随台面投影并随抬升改变宽度与透明度。它们不是 Spine 骨骼、完整口型或逐帧行走成品。

货物使用独立正面与背面图集；`F` 切换视图，`R` 每次旋转 30°，滚轮/按钮缩放。故障裂纹、开盖结构与维修补片还结合程序绘制。维修操作包含拆盖、拖件入槽、接线或标靶/配重校准及确认复测；提供辅助装入/接线入口，操作不依赖极短倒计时。原物在各维修阶段沿用同一位置和绘制尺寸，状态变化通过正背面与叠层表达，工序控件、进度导轨和材料清单分别放在周边。

组装在独立弹窗中进行：主料托盘与两插槽位于上部，端子和连接线位于中部，进度、材料/AP说明与确认按钮放在下部。拖动物料只在弹窗工作区移动，取消拖动时复位；两件真实主料依次入槽并完成端子验证后，确认动作才可用。模型确认前不消耗主料，委修、抵押和封存物不能作为自有组装主料。

交割与订单先保存资金、AP、原物归属和事务ID，再播放视觉结果。快进只结束表现，不重放账务。减少动态省略大位移和装饰运动，保留最终状态与必要文字/轮廓反馈。面板启动以稳定命中区域和透明度反馈为主，按钮不通过整体位移或弹跳改变命中位置；实际目标和相机坐标由原生 UI 命中检测处理。
