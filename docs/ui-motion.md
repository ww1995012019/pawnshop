# 轨道旧货局原生 UI 与动画

当前表现层按空间站方案的 UI-001..008 与 SCN-001..003 组织，版本为 `orbital-p0-v7`。视觉方向为“旧港仪器店”：烟熏玻璃、磨损合金、橡胶托槽与暖白丝印共同构成操作界面，琥珀标出主动作，青色集中用于读数、扫描和当前工具。本文记录当前源码中的布局、交互与已接入素材；各版本的构建、画面和交互验收状态见 [验证记录](validation.md)。

## 页面与空间

`CreatorMain` 继承 `OrbitalMain`。`OrbitalUI` 使用真实 Cocos `Node/Sprite/Label/Graphics/Button/EditBox/Mask`，`OrbitalPanels` 处理维修、仓储、订单与日结；HTML 承载画布和加载页。v7 的公共界面为 56px 高紧凑顶栏与居中的 800×56px 底部 dock，六项导航依次为柜台、鉴定、维修、仓储、订单、日结。议价从柜台进入，设置从顶部进入。经营读数与导航在独立顶底界面层中，不随实物变换。

顶栏直接显示营业日、AP与可用现金，站务按钮显示当前关注值；租金倒计时、应付金额、货物数、在办委托及日结入口收进“站务与经营记录”弹窗。底部两侧分别显示存档状态与当前页面快捷键，导航不再铺满台沿。

柜台的层级依次为舱内背景、半身顾客、原画前景台沿、放大的台面实物与手部、局部交易终端和对白。人物仍在原绘台沿后建立遮挡关系，台面货物绘制区域为 420×316px；右下仅保留一个 360×300px 交易终端，集中展示当前报价、估值、鉴定和议价主动作。“更多”弹窗承载拒绝、抵押和还价次数。左上以订单夹按钮进入委托，顾客姓名、身份与对白合并到左下对白框，移除单独名牌。

鉴定布局为左侧六个工具键、中央无遮底大面板的工作垫、右侧 316px 宽物证册。每个工具键包含实体仪器图、短名及“待取证/已存证”状态，点击或数字键 `1`–`6` 切换。物证册集中展示估值、六段取证进度与最近三条证据；超过三条时通过“查看全部物证”弹窗查看完整记录。没有证据时显示当前工具与操作提示，底部保留“保存证据·返回柜台”。

大读数、正文、仪器标签和辅助说明分级排版。界面材质集中在主操作、工具托座与导轨；次要按钮采用更实的深色底与完整边线，悬停、按下、选中和禁用通过底色、边线与标记区分；纹理集中于主动作与仪器，避免每个矩形都争夺焦点。普通标题和正文采用暖白，报价确认使用琥珀，测量与选中状态使用克制的青色。

## 鉴定台的姿态与边界

鉴定物体以原图中心为旋转轴；工作垫为画布上的 `(212,200,1008,440)`，保留 8px 内边距，并由 `Mask` 裁切。原物仍在 404×404px 的方形绘制区域中显示，`ItemHitBounds.getItemHitBounds` 分别提供每件货物正、背面的 `alphaBBox`。同一份局部范围用于设置 `UITransform` 命中矩形，并传给 `InspectionGeometry` 计算旋转、比例和镜面后的四角包围盒；不再将整张方形透明留白作为每件货物的可见宽高。

`alphaBBox` 来自当前 RGBA 图集的 6×4 分格与 `.035` 裁切内边距，纳入 alpha≥1 的弱光、阴影与抗锯齿边缘，并保留一个源像素的采样边缘。它是保守矩形，不是逐像素轮廓命中，也不代表最小触屏目标尺寸；未登记货物回退为完整方形。图集、排列、裁切或 `contain` 几何改变时，需要同步重新生成边界数据。制造成品 `BND-001` 单独登记其组装绘制范围。

归位请求为中心 `(716,420)`、1.0×、0°和正面。缩放输入范围为 0.45×–1.35×，实际比例按当前物件、正背面与旋转角度计算工作垫可容纳的上限。界面显示实际倍率，到达容量时禁用继续放大。几何层先缩放至可容纳比例，再约束中心；必要时允许适配比例低于输入下限以容纳物体，并规范非有限输入。独立几何检查的运行命令为 `npm run test:inspection-geometry`，实际执行状态以验证记录为准。

物体拖动在按下时记录指针与原物位置；移动时使用“初始物体位置＋当前指针对初始指针的位移”，超过 6px 后进入拖动，再将结果交给统一边界约束。它不累加相邻事件的逐帧增量。物体内的疑点按钮不启动父级拖动；释放或取消时退出拖动状态并再次应用约束。证据卡和探针使用父坐标中的同类位移计算，释放后先还原来源位置与层级，再按落点执行操作；取消时归位。紫外扫描与负载滑块根据按下时数值和横向位移更新。

姿态按当前选件隔离：切换另一件货物或点击归位会重置；同一件货物切换工具、翻面或重绘时沿用当前位姿，再按当前正背面范围重新约束。工具通过六个工具键切换，拖拽物体不再承担选工具操作。阴影根据变换后的可见包围盒更新位置与宽度，拖动时收窄并变淡；疑点、编号、谱线标记和探针接点使用物体局部坐标，随货物平移、旋转和缩放。

## 鼠标与控件反馈

`PointerCursor` 是画布的统一光标管理器，接收原生 Cocos 节点的进入、离开、按下、释放及生命周期事件，再更新画布的原生光标。按钮和可点击柜台实物显示 `pointer`；可拖物、证据卡、探针和滑块显示 `grab`，拖动期间显示 `grabbing`；禁用绑定显示 `not-allowed`，其余区域恢复默认。嵌在可拖物中的按钮优先于父级抓取，模态弹窗打开时只有顶层活动弹窗内的绑定有资格提供反馈。

控件启用状态变化与动画忙碌状态切换会主动刷新光标；页面重建、弹窗开启、移出画布、窗口失焦、页面隐藏、指针取消或捕获丢失时重置相关状态。节点移出界面树、销毁或整棵子树清空时解除绑定。按钮按下与悬停改变其绘制表面，不移动按钮命中几何。

## 通知、弹窗与成交状态

普通通知放在顶栏下方的 28px 单槽信息条中，后来的消息替换前一条，短暂显示后淡出。弹窗打开时清除并隐藏背景通知；弹窗关闭后重新开放通知槽，不堆叠旧消息。弹窗遮罩阻止背景指针输入，键盘焦点也限定在当前弹窗：`Tab` 遍历弹窗按钮，确认键只执行弹窗内焦点项，`Esc` 关闭弹窗；物体旋转、翻面和背景页面快捷键在此期间不触发。文本输入框保持自身输入优先。

交易接受报价后进入锁价状态，报价区域只读；鉴定、还价、拒绝和抵押等交易选择从当前终端移除，右侧仅保留“确认钱货交割”主动作。现金、AP与原物归属在执行交割时结算，接受报价本身不充当交割。成交后的回执和金额反馈位于业务区域，顶部余额显示已提交的状态。

## 字体与行对齐

单行标签采用字号行高；多行说明显式设置换行与段落行距。混合字号的金额、单位和状态通过`baselineLabel`共用字母基线，按锁定3.8.8 Web文本布局计算；不使用空格拼接数值列。原生EditBox会在绑定Label时改写垂直对齐，初始化完成后恢复CENTER。按钮保持固定命中几何，标签居中；大字模式沿用同一行基线与列宽。

## 实物、人物与动效

`OrbitalMotion` 是独立表现层，提供开启舱门、顾客进出、呼吸待机、手持递物、钱币票据、扫描/显纹/谱线/探针/称量/脉冲、维修/组装、印章、升级与日切效果。开场舱门使用临时全屏层；常规特效局限于业务区，鉴定效果进一步裁到工作垫与当前物体范围，印章、升级和日切使用紧凑提示。环境动态只在柜台和议价保留少量暗浮尘与顾客轻微呼吸；仪器和管理页面不铺常驻漂浮装饰。离开页面、快进和销毁时清理旧动画及节点。

当前五位角色使用常态、专注、疑问、满意、拒绝、疲惫六组姿态/表情图集；来访、取证、还价、接受、送客及第3日疲惫等阶段切换可见反应，并配合位移、呼吸摆动、透明度和四姿势手部。进出均沿用台后半身比例和遮挡。手递物体沿短弧线移动，手部接触点跟随货物，阴影跟随台面投影并随抬升改变宽度与透明度。它们不是 Spine 骨骼、完整口型或逐帧行走成品。

货物使用独立正面与背面图集；`F` 切换视图，`R` 每次旋转 30°，滚轮/按钮缩放。破损与磨损以物品正背原画表达，开盖和维修补片结合程序叠层；不再把同一道裂纹覆盖到所有物件及全息投影上。维修操作包含拆盖、拖件入槽、接线或标靶/配重校准及确认复测；提供辅助装入/接线入口，操作不依赖极短倒计时。原物在各维修阶段沿用同一位置和绘制尺寸，状态变化通过正背面与叠层表达，工序控件、进度导轨和材料清单分别放在周边。

组装在独立弹窗中进行：主料托盘与两插槽位于上部，端子和连接线位于中部，进度、材料/AP说明与确认按钮放在下部。拖动物料只在弹窗工作区移动，取消拖动时复位；两件真实主料依次入槽并完成端子验证后，确认动作才可用。模型确认前不消耗主料，委修、抵押和封存物不能作为自有组装主料。

交割与订单先保存资金、AP、原物归属和事务ID，再播放视觉结果。快进只结束表现，不重放账务。减少动态省略大位移和装饰运动，保留最终状态与必要文字/轮廓反馈。面板启动以稳定命中区域和透明度反馈为主，按钮不通过整体位移或弹跳改变命中位置；实际目标和相机坐标由原生 UI 命中检测处理。
