# Creator 网页迁移验证

验证日期：2026年11月7日。目标为浏览器运行，Creator 版本固定为3.8.8。

## 已完成

- `npm run typecheck`：通过，使用从锁定官方引擎源码生成的声明。
- `npm test`：127项经营模型检查通过，覆盖完整七天交易、结算、结局、鉴定进度、旧档迁移与重复交割。
- `npm run build:web`：通过，生成可静态托管的网页、WebP资源与真实Cocos运行时。
- 从干净缓存克隆官方引擎并构建：通过，两次引擎输出SHA256一致。
- WebGL1/WebGL2引擎渲染样例：中文Label、Graphics及远程Sprite通过，无shader或pageerror。
- 浏览器交互：50项断言、45次真实鼠标操作通过；控制台错误、失败资源请求和请求失败均为0。
- 最终构建补查：Tab导航到接待按钮、Enter接待、设置页及首屏加载通过，无控制台错误。

交互覆盖拿取、拖动、滚轮与按钮缩放、旋转、三处痕迹、两个测试触点、错/对编号、还价与接受、单次交割、拖入第8陈列格、刷新恢复、六件分类、减少动态持久化。

布局检查使用1600×900、1366×768和900×600横屏视口；图片、字体和主要操作均已人工查看截图。
