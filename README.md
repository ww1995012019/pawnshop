# 轨道旧货局 Cocos Creator 网页版

使用 **Cocos Creator 3.8.8 与 TypeScript** 开发的空间站当铺经营游戏，按[太空当铺游戏设计与素材需求文档](page://page_f44de03a1914819194a52f23e05cf877)的 P0 页面、物品与首三天流程实现。当前界面版本为 `orbital-p0-v9`；游戏中的场景、货物、人物、工具和 UI 均由原生 Cocos 节点绘制，HTML 只承载画布和加载页。

## 当前实现范围

- 空间站营业柜台、鉴定/维修工作台、仓储/安检区三个场景视图；视觉围绕“旧港仪器店”的烟熏玻璃、磨损合金、暖白丝印和琥珀按键组织。
- UI-001 至 UI-008：柜台、鉴定、维修、仓储安检、议价、订单、日结、设置；居中的底部六项导航贯穿主要业务。
- 24 件 P0 交易货物、6 种鉴定工具、6 种材料、5 位主要角色、12 张订单；另有 5 条维修配方和 1 条维护套组装配方。
- 每日 12 AP、1200 Cr 开局、每日维护 20 Cr；第 7/14/21 天租金为 450/495/545 Cr。模型支持 21 日经营，首三天围绕交易、委修、来源安检与首次设备升级展开。
- 实物正反面切换、拖动、旋转、缩放、六种取证操作、证据报价、原子交割、抵押/赎回、维修拆解组装、10×6 占格仓库、来源登记/隔离及原物订单交付。

内容 ID 与页面的对应关系见 [设计实施对应表](docs/design-traceability.md)。完整 P1 的 60 件货物、8 场景、12 角色与黑市、拍卖、物流、完整施工系统尚未交付。

## 画面与界面

v7 使用紧凑顶栏与居中的六项底部 dock，把操作空间留给场景和实物。顶栏直接显示营业日、AP、现金与站务入口，租金、货物数和在办委托收进“站务与经营记录”弹窗；存档提示与页面快捷键分放在底部两侧。柜台保留台后半身顾客与前景台沿的遮挡关系，台面货物放大，右下集中为一个交易终端。左侧任务入口收为订单夹，顾客姓名、身份与对白合在左下对白框；拒绝、抵押与还价次数从终端的“更多”进入。

鉴定台由左侧六个工具键、中央实物工作垫和右侧简化物证册组成。工具键显示各自仪器、短名与取证状态，支持点击或数字键 `1`–`6` 切换；物证册显示估值、六段取证进度与最近三条证据，更多记录在弹窗中查看。旋转、翻面、缩放和归位控件位于工作垫下缘，当前工具的操作沿用独立桌边区域。

鉴定实物仍绕原图中心旋转；拖动位置按“按下时物体位置＋当前指针相对按下位置的位移”计算，再统一约束。正、背面的 `alphaBBox` 来自已交付透明图集，命中区域与旋转/缩放后的边界约束使用同一份可见范围；它是包含弱光、阴影和采样边缘的保守矩形，不是逐像素轮廓检测。工作垫另有裁切遮罩。归位请求比例为 1.1×，缩放输入范围为 0.45×–1.35×，最终显示比例随物件、正背面和角度适配可用空间；界面显示实际倍率。切换到另一件货物会重置位置、角度、正背面和比例，同一件货物切换工具或重绘页面时保留姿态。

按钮使用更实的底色与边线区分常态、悬停、按下、选中和禁用。统一的 `PointerCursor` 根据 Cocos 节点事件更新画布光标：可点击控件为 `pointer`，可拖物为 `grab`，拖动时为 `grabbing`，禁用控件为 `not-allowed`；页面重建、弹窗、移出画布、窗口失焦与节点移除时清理对应状态。探针和证据卡同样按按下位置计算拖动位移，紫外与负载滑块按按下时的初值和横向位移更新。

顶栏和底栏独立于页面内容与局部动效。常规取证、扫描、维修和结算反馈只在对应业务区域播放，少量环境浮尘仅用于柜台与议价。通知使用顶栏下方的单槽信息条，新消息替换旧消息；弹窗隔离背景鼠标和键盘操作。议价锁价后移除报价编辑和其他交易选择，仅保留“确认钱货交割”主动作。维修各阶段保持原物尺度，组装弹窗分开主料、插槽、端子、进度说明与确认区域。

六种工具使用独立的透明仪器图集。烟玻璃、合金、橡胶托槽、琥珀键与控制导轨使用九宫格材质；主操作和导轨保留实体质感，次要按钮采用较平的实色表面与完整边线。暖白承担正文，琥珀强调当前主动作，青色用于测量、扫描和当前工具。

## 运行与构建

```sh
npm ci
npm run engine:prepare
npm run typecheck
npm test
npm run build:web
npm run preview
```

打开 `http://localhost:4174`。`dist/` 为静态网页产物，可部署到 HTTPS 静态服务器。`npm run build:pages` 另将产物复制到 `play/`，保留仓库既有 GitHub Pages 路径；不要手工修改生成的 `play/game.js`。

`npm run test:orbital` 单独运行空间站规则测试，`npm run test:inspection-geometry` 检查鉴定物体的旋转、缩放、镜面与边界约束；`npm test` 包含这两项及旧灰线模型回归检查。模型、旧版浏览器与各视觉版本分别记录；实际构建、交互和画面验收状态见 [验证记录](docs/validation.md)。

无编辑器构建链使用官方 `@cocos/ccbuild` 编译真实 Cocos 引擎，源码固定提交 `411f98df047c25902f93440d4b22925c2fb65461`，不使用模拟 `cc` 或替代渲染器。首次准备需要 Git、Node.js 22 或更新版本及网络；之后复用 `.cache/cocos/`。相关 WebGL 内置材质说明见 [vendor/README.md](vendor/README.md)。

## Creator 工程

使用 Cocos Dashboard 导入本目录，选择 Creator 3.8.8，资源导入后打开 `assets/scenes/Main.scene`，网页发布目标选择 **Web Desktop**。场景保留 `CreatorMain` 的脚本 UUID，组件继承 `orbital/OrbitalMain`；标准工程和源码引擎网页运行同一份逻辑。

当前云环境没有 Creator 编辑器，Dashboard 导入、资源重新导入与正式编辑器 CLI 构建尚未在本机验证。运行画布为 1600×900，使用 `SHOW_ALL` 适配横屏浏览器；原设计的高清素材源文件交付规格不因画布适配而视为完成。

## 操作与存档

底部入口切换柜台、鉴定、维修、仓储、订单、日结；设置从顶部进入。鉴定台支持拖动物件、方向键移动、滚轮或按钮缩放、`R` 旋转、`F` 切换独立正背面。工具界面分别提供疑点定位、背面紫外扫描、谱峰对齐、双探针接入、校零配重和负载采样；点击左侧六个工具键或按数字键 `1`–`6` 切换仪器，实物保持在工作垫内。`Esc` 返回或关闭当前弹窗；弹窗打开时 `Tab`、确认键与快捷键不作用于背景页面。动画播放时空格可快进。设置包含声音、减少动态、放大文字、导出档案和重新开始。

新版档案键为 **`orbital-save-v3`**，设置键为 **`orbital-prefs-v3`**。新版只读取 schema 3，不将旧世界观的票币、旧物与七日进度转换为 Cr 或空间站物品。原 `greyline-save-v1`、`greyline-save-v2` 与旧设置键保留，重新开始新版不会删除它们。清理浏览器站点数据前可先导出档案；不同域名的本地存档不会自动互通。

| 路径 | 内容 |
| --- | --- |
| `assets/scripts/CreatorMain.ts` | 标准 Creator 场景入口，继承新版游戏组件 |
| `assets/scripts/orbital/OrbitalMain.ts` | 场景、导航、鉴定、议价、输入与存档 |
| `assets/scripts/orbital/OrbitalPanels.ts` | 维修、仓储安检、订单、日结与设置 |
| `assets/scripts/orbital/OrbitalUI.ts` | 仪器材质、半身人物、工具图集、原生控件、按钮状态与统一指针绑定 |
| `assets/scripts/orbital/PointerCursor.ts` | 画布光标状态、可拖与禁用反馈、弹窗优先级及生命周期清理 |
| `assets/scripts/orbital/ItemHitBounds.ts` | 正背面图集的保守 alphaBBox，供命中区域与工作垫边界共用 |
| `assets/scripts/orbital/OrbitalMotion.ts` | 人物、手递、取证、维修、扫描、结算等表现 |
| `assets/scripts/orbital/InspectionGeometry.ts` | 中心姿态、变换后包围盒、工作垫边界与缩放适配的纯数学约束 |
| `assets/scripts/orbital/data.ts`、`types.ts`、`model.ts` | 内容、类型、经济规则与存档校验 |
| `assets/resources/art/orbital-*` | 三张场景、正/背面货物、五角色六姿态、六仪器与界面材质图集 |
| `tests/orbital.test.cjs` | 新版状态、经济、归属与异常边界测试 |
| `scripts/test-inspection-geometry.mjs` | 独立四角变换校验，覆盖连续扫角、镜面、极端拖拽、缩放与无效输入 |
| `assets/scripts/game/`、`tests/model.test.cjs` | 保留的旧版模型及回归测试 |

当前三张场景是 1672×941 单张背景；货物正、背面各一张 1536×1024 图集，故障、开盖与修复标记还结合程序叠层。新增六仪器图集与界面九宫格材质图集各为 1536×1024。它们不是已交付的 4K 分层生产源文件。五角色已有常态、专注、疑问、满意、拒绝、疲惫六组姿态/表情切换，每组2172×724图集包含五人物；配合进出、呼吸和四姿势手部表现。它们不是 Spine 骨骼、完整口型或逐帧角色行走成品。当前内容与后续素材边界见 [UI 与动画说明](docs/ui-motion.md)。

中文字体与许可保存在资源目录；网页构建将 PNG 转为 WebP，保留 Creator 工程中的 PNG 与 `.meta`。程序提示音仍为原型音效；Cocos 引擎与测试 effect 按 MIT 许可分发，许可见 `vendor/COCOS-LICENSE.txt`。
