# 灰线旧货铺 Cocos Creator 网页版

使用 **Cocos Creator 3.8.8、TypeScript** 开发的浏览器经营游戏。游戏场景、人物、物品、按钮、鉴定台和窗口均由真实 Cocos 节点渲染；网页只承载画布和加载页。

本次把原 `objects-v6` 网页原型迁移为可维护的 Creator 工程，保留原有 12 件旧物、6 位顾客、7 天经营、180 票开局、议价、鉴定、陈列、社区委托、账本与结局。三种鉴定操作分别为痕迹检查、双触点测试和编号对照；物品可拖动、旋转、缩放与查看铭牌。多角度成品美术和设计文档中的 60 件货物等扩展内容不计入本次迁移完成范围。

## 本轮美术与动画调整

本轮界面版本为 **`creator-web-v2`**。原生 Cocos UI 重新接入店铺背景、人物与旧物图集、木质操作框、纸张告示、票据、对话框、货柜及功能图标，让接待、鉴定与交易发生在可见的柜台和货架上。按钮补充悬停、按压、选中、禁用与键盘焦点反馈；库存、鉴定、图鉴、账本、委托和设置使用相同的材质与窗口样式。

动画代码本轮接入以下表现。核心浏览器检查 **37/37通过**，最终构建另完成 **25/25精选检查**，打烊日切与跳过操作也已实测：

- 开店卷帘揭幕；顾客走入、呼吸待机与离场；灯光和浮尘环境动态。
- 左右手张开、握持共四种手势，配合袖口、物品弧线和接触阴影，表现取物、递物、轻放与上架。
- 痕迹放大扫描、编号扫描、功能采样、触点连线与负载波形；证据和议价结果盖章。
- 交割钱币流向、金额变化、成交票据；打烊与次日营业的遮罩切换。
- 动画期间操作锁定、跳过表现与“减少动态”；减少动态已验证立即生效。

本轮核心验收完成22次真实鼠标动作，控制台、页面异常和资源错误均为0；已核对扫描、连线、波形、结果印章、交割和上架的可见中间帧，以及双击去重和刷新后的存档一致性。表现对应资源、触发动作与验收标准见 [UI 与动画说明](docs/ui-motion.md)，精选复核与收尾状态见 [验证记录](docs/validation.md)。源码引擎的浏览器构建已能运行，Creator编辑器导入仍未本机验证。

## 用 Creator 编辑器打开

1. 用 Cocos Dashboard 导入此目录，选择 **Creator 3.8.8**。
2. 等待资源导入，打开 `assets/scenes/Main.scene`。
3. 浏览器预览。正式发布在构建面板选择 **Web Desktop**。

`CreatorMain` 在启动时创建原生 Canvas、正交相机与 UI。项目基准分辨率为 **1600×900，SHOW_ALL**，以电脑横屏浏览器为主要体验，触摸拖拽同样可用。

当前云环境没有 Creator 编辑器。场景与 `.meta` 依据官方 3.8.8 工程样例制作，脚本通过真实引擎类型检查；编辑器资源导入与正式编辑器构建仍需在安装了该版本的机器验证。

## 不安装编辑器的网页验证

本仓库另提供一条 **官方引擎源码构建链**，用于 CI 和浏览器验证。它通过官方 `@cocos/ccbuild` 编译同版本真实引擎，运行同一份游戏组件，不使用替代渲染器或模拟的 `cc` API。

```sh
npm ci
npm run engine:prepare
npm run typecheck
npm test
npm run build:web
npm run preview
```

打开 `http://localhost:4174`。`dist/` 是静态网站，可放到支持 HTTPS 的普通静态服务器。现有仓库以 `gh-pages` 作为发布分支，因此同时保留 `play/` 网页产物和根入口跳转；合并迁移分支后原地址仍能进入游戏。更新发布文件使用 `npm run build:pages`，不要手工修改 `play/game.js`。首次准备引擎需要 Git、Node.js 22 或更新版本及网络，编译会花费数分钟；后续复用 `.cache/cocos/`。

源码引擎固定为 `cocos/cocos-engine` 提交 `411f98df047c25902f93440d4b22925c2fb65461`。无编辑器验证链使用官方测试 effect 生成必要的 WebGL 内置材质；Creator 编辑器构建使用正常的编辑器资源流水线。两条路径的差异见 `vendor/README.md`。

Creator 的标准项目标识 `package.json.type` 为 `3d`，部分通用 Node 打包工具会对此给出提示；项目使用 `.mjs/.cjs` 明确区分工具模块，不依赖该字段的 Node 模块语义。

## 操作与存档

- 鼠标或触摸：接待、议价、拿取旧物、拖入鉴定工具、点击痕迹、连接测试触点、分类与陈列换位。
- 鉴定台：滚轮或加减按钮缩放，`R` 旋转，`F` 查看铭牌，方向键移动。
- `I` 打开库存，`Esc` 返回；`Tab` 在操作按钮间移动，回车或空格执行。
- 设置中可关闭声音、减少动态、放大文字和导出存档。

存档使用当前站点的浏览器本地存储 `greyline-save-v2`。首次读取同一来源中的旧 `greyline-save-v1` 时自动验证并迁移，保留原键供回退。跨域部署不能自动读取另一个域名的存档。更换浏览器或清理站点数据前，请先导出备份。

## 代码与资源

| 路径 | 内容 |
| --- | --- |
| `assets/scripts/CreatorMain.ts` | Creator 启动、界面、原生输入、声音与存档集成 |
| `assets/scripts/ui/GameUI.ts` | 原生 UI、图片与图集、按钮状态、窗口和通知 |
| `assets/scripts/ui/MotionDirector.ts` | 开店、顾客、手势递物、鉴定、交割及日切的表现层 |
| `assets/scripts/game/` | 独立于渲染器的商品数据、经营状态与存档迁移 |
| `assets/resources/` | 原图、真实 TTF、程序提示音与 Creator 资源元数据 |
| `assets/scenes/Main.scene` | Creator 启动场景 |
| `web/` | 无编辑器 Web 验证入口与真实内置材质注册 |
| `scripts/` | 固定版本引擎准备、网页构建和本地预览 |
| `tests/model.test.cjs` | 经营、交易去重、日结与存档检查 |

原发布包没有 React/TypeScript 源工程。此处依据可验证的原发布行为提取数据并重新实现规则，旧压缩 JS/CSS 不进入 Creator 的资源目录。原发布版本仍保留在 Git 历史中。

Web 构建把 PNG 转为 WebP，并预加载首屏及主要操作需要的贴图；原始 PNG 和标准导入元数据保留在 Creator 工程里。角色动态的范围是整体立绘位移、轻微摆动和透明度变化，手部使用四种姿势的独立手套图集；目前没有骨骼表情或完整角色逐帧动作。铭牌页也不声称是独立背面美术。新增多视图、拆件、骨骼表情和工作场景时，应同时补齐源素材与交互数据。

字体为原项目的 Noto Serif CJK 子集，已转换为真实 TrueType，许可保存在资源中；新增长篇剧情应重新检查字形覆盖。音频为原创程序生成的原型提示音，不是最终拟音或配乐。Cocos 引擎及测试 effect 依照 MIT 许可分发，见 `vendor/COCOS-LICENSE.txt`。
