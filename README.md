# 轨道旧货局 Cocos Creator 网页版

使用 **Cocos Creator 3.8.8 与 TypeScript** 开发的空间站当铺经营游戏，按[太空当铺游戏设计与素材需求文档](page://page_f44de03a1914819194a52f23e05cf877)的 P0 页面、物品与首三天流程实现。当前界面版本为 `orbital-p0-v13`；游戏中的场景、货物、人物、工具和 UI 均由原生 Cocos 节点绘制，HTML 只承载画布和加载页。

## 当前实现范围

- 空间站营业柜台、鉴定/维修工作台、仓储/安检区三个场景视图；视觉围绕“旧港仪器店”的烟熏玻璃、磨损合金、暖白丝印和琥珀按键组织。
- UI-001 至 UI-008：柜台、鉴定、维修、仓储安检、议价、订单、日结、设置；居中的底部六项导航贯穿主要业务。
- 24 件 P0 交易货物、6 种鉴定工具、6 种材料、5 位主要角色、12 张订单；另有 5 条维修配方和 1 条维护套组装配方。
- 每日 12 AP、1200 Cr 开局、每日维护 20 Cr；第 7/14/21 天租金为 450/495/545 Cr。模型支持 21 日经营，首三天围绕交易、委修、来源安检与首次设备升级展开。
- 实物正反面切换、拖动、旋转、缩放、六种取证操作、证据报价、原子交割、抵押/赎回、维修拆解组装、10×6 占格仓库、来源登记/隔离及原物订单交付。

内容 ID 与页面的对应关系见 [设计实施对应表](docs/design-traceability.md)。完整 P1 的 60 件货物、8 场景、12 角色与黑市、拍卖、物流、完整施工系统尚未交付。

## 画面与界面

v12 把界面从“网页面板”改成游戏界面，统一为“旧港仪器店”的实物语言：

- **标题画面**：启动先显示店名、标语与“开门营业 / 继续营业 · 第 N 天”“新开一家店”“设置”；`Enter` 开始，确认后播放开舱动画。标题期间只显示场景原画。
- **三类材质**：主要窗口用满强度的锈蚀金属铆钉框（`orbital-ui-surfaces` 九宫格，过去只以 15–30% 透明度叠加）；报价、估值、行动点等读数用 CRT 屏（扫描线、辉光、等宽数码字体）；订单、日结与价签用热敏纸票据（撕边、深色油墨字、图钉与印章）。
- **HUD**：左上店名铭牌；中间营业日、行动点电池格与现金三联仪表，均配图标；右上图鉴、站务（关注度角标）、声音、设置四个图标键，悬停显示说明。
- **底部导航**：六个带统一风格图标的按键，当前页琥珀描边发光，订单键显示在办数量角标。存档提示只在失败时出现，操作提示不再常驻。
- **按钮**：所有按钮都是实体按键——主动作为琥珀黄铜，其余为磨损石墨，悬停提亮、按下变暗、选中琥珀描边。弹窗为重型机框加琥珀标题铭牌与图标关闭键。
- **去除开发痕迹**：去掉 `WAREHOUSE / SCN-003`、`DELIVERY MANIFEST` 等英文小标签，以及 `ITM-011`、`ORD-001`、`NO. 001` 等内部编号；订单说明里的工序编号显示为工序名；页面标题改为带图标的铭牌。

图标与票据、CRT 贴图由 `scripts/generate-ui-art.mjs` 从矢量源生成（`orbital-hud.png` 24 枚图标，`orbital-ui-kit.png` 纸张与 CRT），数码字体为 JetBrains Mono Bold（`orbital-mono.ttf`，Apache-2.0）。

**新手引导与说明**：新档开局后自动进入 15 步引导。遮罩会挖出当前要操作的区域并配上说明卡片；需要玩家操作的步骤要等真正完成（接客、拿起实物、侧光取证、回柜台、议价、接受、交割）才进入下一步，随时可以跳过。维修、仓储、订单、日结页第一次打开时各有一条提示。顶栏「?」和标题画面「玩法说明」都能打开八节《经营手册》（目标与节奏、柜台交易、鉴定仪器、维修与组装、仓储与安检、订单委托、日结与升级、操作提示），手册里可以重新播放引导。是否看过引导记在 `orbital-tutorial-v1` / `orbital-tips-v1` 两个本地键里。

**动作动画**：六种鉴定工具的取证动画都以实物为中心，画在整张工作垫上，不再被裁成半个：
- 放大镜依次扫过三处疑点并闪光；
- 紫外光束扫过实物，荧光点和旧编号逐格显影；
- 三色谱线从实物射入 CRT 屏，波峰锁定后打勾；
- 两个端子之间拉出电弧，示波器描出波形；
- 天平升起、砝码落盘、刻度盘指针归位；
- 夹钳合拢后放出脉冲环，负载波形逐段打印。

其他动作：取证成功时，一张物证小票飞进物证册，对应的物证格和估值屏会闪一下；仓库扫描有扫描面、网格和进度条；维修有火花、热点和冷却烟，完成后有一道高光扫过；交割时金币飞向顶栏现金，现金数字滚动增减；行动点减少时飘出「−N AP」；交付、登记、升级、打烊都有落下的印章；换天时有闸门合拢、显示「第 N 天」、再打开的过场；切换页面时内容淡入上浮。打开「减少动态」后，这些动画都会跳过。

**H5 / 手机**：游戏固定横屏。竖着拿手机时画面自动旋转 90° 铺满屏幕，触摸坐标由引擎换算；禁止双指缩放、双击放大与页面回弹；安卓浏览器首次点击进入全屏并尝试锁定横屏，iOS 可“添加到主屏幕”以无地址栏方式打开。触屏设备上 24 号以下的文字放大（手机约 1.32 倍、平板约 1.14 倍，超出文字框时自动缩回），顶栏图标键下方常显文字说明，键盘按键提示改为对应按钮。界面仍是同一套 1600×900 布局，手机上按钮和正文偏小，专门的手机布局尚未制作。

柜台为台后半身顾客、台面实物与纸质价签，右下是带 CRT 屏的交易终端；对白框带琥珀姓名牌。议价时左侧对白框合并顾客需求与耐心格，底部还价台由报价屏、±10 键、可拖到报价屏的物证小票和提交键组成。

鉴定台由左侧六个工具键、中央实物工作垫和右侧简化物证册组成。工具键显示各自仪器、短名与取证状态，支持点击或数字键 `1`–`6` 切换；物证册显示估值、六段取证进度与最近三条证据，更多记录在弹窗中查看。旋转、翻面、缩放和归位控件位于工作垫下缘，当前工具的操作沿用独立桌边区域。

鉴定实物仍绕原图中心旋转；拖动位置按“按下时物体位置＋当前指针相对按下位置的位移”计算，再统一约束。正、背面的 `alphaBBox` 来自已交付透明图集，命中区域与旋转/缩放后的边界约束使用同一份可见范围；它是包含弱光、阴影和采样边缘的保守矩形，不是逐像素轮廓检测。工作垫另有裁切遮罩。归位请求比例为 1.1×，缩放输入范围为 0.45×–1.35×，最终显示比例随物件、正背面和角度适配可用空间；界面显示实际倍率。切换到另一件货物会重置位置、角度、正背面和比例，同一件货物切换工具或重绘页面时保留姿态。

按钮的常态、悬停、按下、选中和禁用通过金属键帽的明暗、琥珀描边与透明度区分。统一的 `PointerCursor` 根据 Cocos 节点事件更新画布光标：可点击控件为 `pointer`，可拖物为 `grab`，拖动时为 `grabbing`，禁用控件为 `not-allowed`；页面重建、弹窗、移出画布、窗口失焦与节点移除时清理对应状态。探针和证据卡同样按按下位置计算拖动位移，紫外与负载滑块按按下时的初值和横向位移更新。

顶栏和底栏独立于页面内容与局部动效。常规取证、扫描、维修和结算反馈只在对应业务区域播放，少量环境浮尘仅用于柜台与议价。通知使用顶栏下方的单槽信息条，新消息替换旧消息；弹窗隔离背景鼠标和键盘操作。议价锁价后移除报价编辑，保留“确认钱货交割”和“取消本次交易”。维修各阶段保持原物尺度，组装弹窗分开主料、插槽、端子、进度说明与确认区域。

六种工具使用独立的透明仪器图集。暖白承担正文，琥珀强调当前主动作与金额，青色用于测量、扫描、CRT 读数和当前工具；纸质票据上改用深色油墨与锈红强调。

## v11 交易与货源

报价有实物范围、NPC底价与预算。最多三轮议价，连续两次悬殊报价会送走来客；物证只对当前实物的相关工具生效。顾客按功能、真伪和品相需求选货，交割时再次核对价格、来源和归属。每笔交割1AP，取消不转移钱货。

货物36类，顶栏“货物图鉴”可查看全部正反面、工具、维修建议及公开到货预告。每天六位预约，D4起种子货源轮换，同型号有不同批次状态。24张订单错峰开放，含D4–21后续委托；新增6张维修配方。旧schema3档案保留进度并补齐新订单，未交割异常报价解锁后恢复合法报价。

## 运行与构建

```sh
npm ci
npm run engine:prepare
npm run typecheck
npm test
npm run build:web
npm run preview
```

打开 `http://localhost:4174`。`dist/` 为静态网页产物，可部署到 HTTPS 静态服务器。`npm run build:pages` 另将产物复制到 `play/`，保留仓库既有 GitHub Pages 路径；不要手工修改生成的 `play/game.js`。

`npm run test:orbital` 单独运行空间站规则测试，`npm run test:inspection-geometry` 检查鉴定物体的旋转、缩放、镜面与边界约束；`npm test` 包含这两项及旧灰线模型回归检查。模型、旧版浏览器与各视觉版本分别记录；实际构建、交互和画面验收状态见 [验证记录](docs/validation.md)。

无编辑器构建链使用官方 `@cocos/ccbuild` 编译真实 Cocos 引擎，源码固定提交 `411f98df047c25902f93440d4b22925c2fb65461`，不使用模拟 `cc` 或替代渲染器。首次准备需要 Git、Node.js 22 或更新版本及网络；之后复用 `.cache/cocos/`。相关 WebGL 内置材质说明见 [vendor/README.md](vendor/README.md)。

## Creator 工程

使用 Cocos Dashboard 导入本目录，选择 Creator 3.8.8，资源导入后打开 `assets/scenes/Main.scene`，网页发布目标选择 **Web Desktop**。场景保留 `CreatorMain` 的脚本 UUID，组件继承 `orbital/OrbitalMain`；标准工程和源码引擎网页运行同一份逻辑。

当前云环境没有 Creator 编辑器，Dashboard 导入、资源重新导入与正式编辑器 CLI 构建尚未在本机验证。运行画布为 1600×900，使用 `SHOW_ALL` 适配横屏浏览器；原设计的高清素材源文件交付规格不因画布适配而视为完成。

## 操作与存档

底部入口切换柜台、鉴定、维修、仓储、订单、日结；设置从顶部进入。鉴定台支持拖动物件、方向键移动、滚轮或按钮缩放、`R` 旋转、`F` 切换独立正背面。工具界面分别提供疑点定位、背面紫外扫描、谱峰对齐、双探针接入、校零配重和负载采样；点击左侧六个工具键或按数字键 `1`–`6` 切换仪器，实物保持在工作垫内。`Esc` 返回或关闭当前弹窗；弹窗打开时 `Tab`、确认键与快捷键不作用于背景页面。动画播放时空格可快进。设置包含声音、减少动态、放大文字、导出档案和重新开始。

新版档案键为 **`orbital-save-v3`**，设置键为 **`orbital-prefs-v3`**。新版只读取 schema 3，不将旧世界观的票币、旧物与七日进度转换为 Cr 或空间站物品。原 `greyline-save-v1`、`greyline-save-v2` 与旧设置键保留，重新开始新版不会删除它们。清理浏览器站点数据前可先导出档案；不同域名的本地存档不会自动互通。
